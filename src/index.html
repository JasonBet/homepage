My work

ML Trading Strategy

A machine learning trading strategy built in Python with Pandas and NumPy. Implemented a Random Forest classifier over five hand-built technical indicators (MACD, RSI, %B, Momentum, and CCI), each feeding a vote-aggregation signal generator. Built a market simulator with configurable commission and market impact to evaluate the strategy. The learner finished a two-year out-of-sample period profitable while a buy-and-hold benchmark on the same equity returned −8.4%. Full writeup, results, and limitations in the repo.

Battleship

The classic game of Battleship on the web, built with HTML, CSS, and JavaScript using ES6 modules and an event-driven architecture that keeps game logic fully separate from UI rendering. Developed with Test-Driven Development using Jest. Implemented a heuristic enemy AI that switches from random search to targeted hunt mode after a successful hit, plus a randomize button that auto-populates the player's fleet.

Dungeon Crawler

A 2D dungeon crawler built by a student team, inspired by early Legend of Zelda and Binding of Isaac. Led scrums across the team's Agile development cycle to implement core game mechanics. Programmed C# scripts for enemy AI behaviors, developed the player health system, built UI components including the player inventory, and designed the final two levels of the game.

Resume Builder

A resume builder web application developed in React with HTML, CSS, and JavaScript. Implemented a live resume preview by lifting state to a central component to allow state sharing across the form. Added data persistence via localStorage so users can return without losing progress. Engineered a one-click PDF export by integrating react-to-print and tuning print media rules.
